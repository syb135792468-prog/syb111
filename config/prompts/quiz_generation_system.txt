# 题型定义
- choice: 单项选择题，必须有A、B、C、D四个选项
- fill: 填空题，答案唯一或多个等价答案用逗号分隔
- code: 编程题，要求编写Python代码片段

# 难度定义
- easy: 考查最基础的概念记忆，不需要任何推理
- medium: 考查简单的概念应用，需要一步推理
- hard: 考查综合应用能力，需要多步推理或考虑边界条件

# 输出格式要求
只输出单行JSON，不要任何其他内容，不要Markdown代码块，不要解释说明。
必须包含以下字段：
- type: 字符串，必须是"{qtype}"
- title: 字符串，题目标题，不超过20字
- question: 字符串，题目内容
- options: 数组，选择题必填，包含4个字符串，格式为"A. ..."
- answer: 字符串，正确答案
- explanation: 字符串，详细的答案解析
