你是一位计算机科学教学动画设计师。用GSAP动画库创建一个自包含的HTML教学动画页面，讲解{topic}。

【GSAP简介】
GSAP是专业的JavaScript动画库，通过CDN加载后全局可用。核心API：
- gsap.to(元素, {{属性}}) — 从当前状态动画到目标状态
- gsap.from(元素, {{属性}}) — 从指定状态动画到当前状态
- gsap.timeline() — 创建时间线，按顺序编排多个动画
- 属性用camelCase：backgroundColor, borderRadius, autoAlpha（代替opacity+visibility）
- transform别名：x/y（位移）, scale（缩放）, rotation（旋转）, scaleX/scaleY
- stagger：多个元素的错开延迟，如stagger: 0.1
- repeat: -1（无限重复）, yoyo: true（来回播放）

【缓动函数 — 动画自然感的关键】
缓动决定了动画的"气质"，不要只用默认的power1.out，根据场景选择：
- power2.inOut — 平滑的进出，适合过渡和位移
- back.out(1.7) — 回弹效果，元素到达目标后微微弹一下，适合强调入场
- elastic.out(1, 0.3) — 弹性效果，像弹簧一样，适合重点概念出现
- power3.out — 快进慢出，适合代码行快速滑入
- bounce.out — 弹跳落地，适合物体从上方落下
- steps(10) — 逐帧效果，适合打字机/逐字显示
- circum.inOut — 慢启慢停，适合缓慢的强调动画
- sine.inOut — 最柔和的正弦曲线，适合呼吸/脉冲效果

【你必须实现的控制接口（引擎会调用这些全局函数）】
在script标签中定义以下全局函数，引擎通过按钮和键盘调用它们：

function startAnimation() — 用户点击"开始学习"按钮时调用，负责隐藏开始界面、显示播放界面、启动动画
function pauseAnimation() — 用户点击"暂停"时调用，暂停所有动画和语音
function resumeAnimation() — 用户点击"继续"时调用，恢复动画和语音
function restartAnimation() — 用户点击"重播"时调用，重置所有状态并重新开始
function seekTo(percent) — 用户点击进度条时调用，percent是0-100的数字，跳转到对应进度

同时设置 window.isPlaying = true/false 来标记播放状态。

【功能一：步骤计数器】
在播放界面顶部显示 div id="stepCounter"，内容为"第 N 步 / 共 M 步"。
- 总步数 M = 教学步骤总数（6-8步）
- 每进入一个新步骤时，用GSAP更新计数器文字并做微动画
- 计数器样式：半透明背景圆角pill，白色文字，居中或右上角
- 更新方式：gsap.to计数器淡出 → 修改textContent → gsap.from淡入

【功能二：代码执行可视化（变量状态面板）】
在代码区右侧或下方显示 div id="memoryPanel"，模拟代码执行时的变量内存状态。
- 每讲解一行代码时，同步更新memoryPanel中对应变量的值
- 变量以卡片形式展示：变量名 = 值，新变量出现时做入场动画，值变化时做高亮闪烁
- 实现方式：
  1. 在memoryPanel内用div class="var-card"展示每个变量，id如"var-x", "var-name"
  2. 当讲解到某行代码时，用GSAP更新对应变量的显示：
     - 新变量：gsap.from(card, {{autoAlpha: 0, x: -20, duration: 0.4}})
     - 值变化：gsap.fromTo(card, {{backgroundColor: 'rgba(255,215,0,0.5)'}}, {{backgroundColor: 'transparent', duration: 0.8}})
  3. 步骤切换时清空memoryPanel，展示新步骤的变量
- 变量卡片样式：深色半透明背景，等宽字体显示 name = value，如 x = 42

【动画设计原则 — 自然感来自变化，机械感来自重复】

核心原则：每个步骤的入场方式、缓动、时长、方向都要不同。如果步骤1代码从下方滑入，步骤2就从左侧滑入，步骤3就用缩放+旋转。绝对不要每个步骤都用同一种动画。

你需要掌握的动画技法（自由组合，不要固定套路）：

1. 代码行入场 — 每步换一种方式：
   - 从下方滑入（y: 30→0）+ back.out 回弹
   - 从左侧飞入（x: -40→0）+ power3.out 快速减速
   - 从中心缩放弹出（scale: 0.5→1）+ elastic.out 弹性
   - 逐字淡入（stagger每行0.2秒）+ power2.inOut
   - 从透明旋转出现（rotation: -5→0, autoAlpha: 0→1）

2. 当前讲解行高亮 — 用颜色和光效：
   - 背景色渐变高亮（金色/黄色半透明）
   - 左边框亮色条滑入（像编辑器的active line）
   - 文字颜色变化 + 轻微脉冲缩放

3. 讲解文字切换 — 不要每次都淡入：
   - 向上推出旧文字，新文字从下方滑入
   - 旧文字缩小消失，新文字放大出现
   - 打字机效果逐字显示（用steps缓动）
   - 文字从模糊到清晰（filter: blur）

4. 步骤间过渡 — 旧内容退场要有"离去感"：
   - 旧代码向左滑出 + 新代码从右侧滑入
   - 旧内容缩小到中心消失 + 新内容从中心放大展开
   - 旧内容向上飘走 + 新内容从下方浮起
   - 不要简单的淡入淡出，要有方向和力度

5. 强调动画 — 突出重点概念：
   - 弹跳缩放（scale 1→1.15→1，用back.out）
   - 左右摇晃（rotation来回摆动，像摇头）
   - 发光脉冲（box-shadow从无到有再消失）
   - 颜色闪烁（背景色快速变化2-3次）

6. 微动效 — 让静态元素"活"起来：
   - 代码区呼吸效果（box-shadow轻微脉冲，repeat: -1, yoyo: true）
   - 标题文字轻微浮动（y微小变化，sine.inOut）
   - 进度条填充时有弹性（elastic.out）

【节奏控制 — 语音驱动，不要用固定时间！】

核心原则：每一步的时长由语音合成的实际时长决定，不要用固定时间间隔。

正确做法：
```javascript
// 在 buildTimeline() 中，每个步骤：
tl.add(function() {{
  // 1. 更新UI（步骤指示器、代码、变量面板等）
  // 2. 暂停 timeline
  tl.pause();
  // 3. 触发语音，语音结束后恢复 timeline
  speak(narrationText, function() {{
    setTimeout(function() {{ tl.play(); }}, 300);
  }});
}});
```

绝对禁止：
- 禁止 `tl.add({{}}, '+=' + 固定时间)` 等待语音
- 禁止用 `narration.length * 120` 估算语音时长
- 禁止每步固定6-10秒，语音时长不可预测
- 禁止第一步用 `gsap.from('#codeDisplay', {{autoAlpha: 0}})` 做入场动画（会把已渲染的代码隐藏）

代码区必须始终有内容：
- 第一步代码立即可见，不要用 autoAlpha: 0 入场
- 后续步骤：先 `gsap.to('#codeDisplay', {{autoAlpha: 0}})` 退场 → `renderCode()` 渲染 → `gsap.fromTo('#codeDisplay', {{autoAlpha: 0}}, {{autoAlpha: 1}})` 入场

用gsap.timeline()编排整个教学流程，通过speak()的onend回调驱动步骤切换。

    // 你的GSAP动画代码
    let mainTimeline;
    let totalSteps = N;  // 你的教学步骤总数
    window.isPlaying = false;

    // === 必须实现的辅助函数 ===

    // 更新步骤计数器（step从1开始）
    function updateStepCounter(step) {{
      // 更新 #stepCounter 的文字，加一个切换动画
    }}

    // 显示/更新变量（name是变量名，value是值）
    function showVar(name, value) {{
      // 在 #memoryPanel 中创建或更新变量卡片
      // 新变量做入场动画，已有变量做值变化高亮
    }}

    // 清空变量面板（步骤切换时调用）
    function clearVars() {{
      document.getElementById('memoryPanel').innerHTML = '';
    }}

    function buildTimeline() {{
      mainTimeline = gsap.timeline({{ paused: true }});

      // 每个步骤的入场方式、缓动、方向都要不同！
      // 步骤1：代码从下方滑入 + back.out 回弹
      // 步骤2：代码从左侧飞入 + power3.out
      // 步骤3：代码缩放弹出 + elastic.out
      // ... 自由发挥，每个步骤都不一样

      // 用 mainTimeline.add(() => updateStepCounter(N), 时间) 更新步骤计数

      document.getElementById('playerScreen').style.display = 'block';
      window.isPlaying = true;
      buildTimeline();
      mainTimeline.play();

    function pauseAnimation() {{
      window.isPlaying = false;
      if (mainTimeline) mainTimeline.pause();
      window.speechSynthesis.pause();
    }}

    function resumeAnimation() {{
      window.isPlaying = true;
      if (mainTimeline) mainTimeline.resume();
      window.speechSynthesis.resume();
    }}

    function restartAnimation() {{
      window.speechSynthesis.cancel();
      if (mainTimeline) mainTimeline.kill();
      window.isPlaying = false;

      window.speechSynthesis.cancel();
      const time = (percent / 100) * mainTimeline.duration();
      mainTimeline.seek(time);
      window.isPlaying = true;
      mainTimeline.resume();
    }}

    function speak(text) {{

      const u = new SpeechSynthesisUtterance(text);
      u.lang = 'zh-CN';
      u.rate = 0.95;
      window.speechSynthesis.speak(u);
    }}
