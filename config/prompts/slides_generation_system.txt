## 什么是函数？

- 函数是一段**可重复调用**的代码块
- 接收**输入参数**，执行操作，**返回结果**
- 好处：减少重复代码、提高可读性、便于调试

> 类比：函数就像一台榨汁机 —— 放入水果（参数），按下按钮（调用），得到果汁（返回值）

---

## 定义函数的语法

使用 `def` 关键字定义，函数名遵循蛇形命名法：

```python
def greet(name):
    """向用户打招呼"""
    return f"你好，{{name}}！"

# 调用函数
message = greet("小明")
print(message)  # 你好，小明！
```

---

## 参数与默认值

- 可以设置**默认参数**，调用时可省略
- 使用关键字参数让调用更清晰

```python
def power(base, exponent=2):
    return base ** exponent

print(power(3))      # 9  （默认平方）
print(power(3, 3))   # 27 （立方）
print(power(2, 10))  # 1024
```

---

## 多返回值

Python 函数可以一次性返回多个值，本质是返回元组：

```python
def min_max(numbers):
    return min(numbers), max(numbers)

lo, hi = min_max([3, 1, 4, 1, 5, 9])
print(f"最小值: {{lo}}, 最大值: {{hi}}")
# 最小值: 1, 最大值: 9
```

---

## 常见错误

**忘记 return 语句** — 函数默认返回 `None`：

```python
# 错误示例
def add(a, b):
    a + b  # 没有 return！

result = add(1, 2)
print(result)  # None
```

**正确写法**：

```python
def add(a, b):
    return a + b  # 加上 return

print(add(1, 2))  # 3
```

## 实战练习

编写一个函数 `is_palindrome(s)`，判断字符串是否为回文：

```python
def is_palindrome(s):
    s = s.lower().replace(" ", "")
    return s == s[::-1]

# 测试
print(is_palindrome("racecar"))  # True
print(is_palindrome("hello"))    # False
print(is_palindrome("A man a plan a canal Panama".replace(" ", "")))  # True
```

- 支持默认参数、多返回值、关键字参数
- **函数是 Python 代码组织的基本单元**
