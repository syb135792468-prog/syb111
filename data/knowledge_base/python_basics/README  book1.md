## 一、Python语言概述
1.  **语言定位**：Python是一款应用广泛的通用高级解释型程序设计语言，核心设计哲学为代码可读性与语法简洁性，支持跨平台运行。可开发GUI应用、Web应用、游戏程序等，尤其擅长科学计算、数据处理与分析、数据可视化、机器学习与人工智能领域，豆瓣、知乎、今日头条、Instagram等知名产品均有Python技术栈应用。
2.  **发展历程**：1990年正式诞生，名称源自电视剧《蒙提·派森的飞行马戏团》；2000年10月发布Python 2.0；2008年12月发布Python 3.0，该版本相对2.0完成重大升级，且二者互不兼容，本书采用Python 3.11.9版本。
3.  **核心特点**：语法简洁、平台无关、胶水语言（可整合C/C++/Java等多语言代码）、完全面向对象、类库资源丰富。
4.  **类库体系**：分为标准库与第三方库，二者调用方式一致，共同构成Python计算生态。标准库由Python官方提供，随安装默认自带，提供基础功能；第三方库由第三方开发者提供，需额外安装，可通过PyPI官网（https://pypi.org/）查询获取。Python学习的两大核心为基础语法学习、各类库的运用。

## 四、Python编程快速上手
本部分为章节核心，完整讲解Python入门核心语法、程序结构与开发方法，核心知识点如下：
1.  **基本输入输出**：核心为两个内置函数。`print()`函数用于内容输出，支持多对象输出，可通过`end`参数设置行尾结束符、`sep`参数设置多对象分隔符；`input()`函数用于接收用户键盘输入，返回值为字符串，可设置输入提示信息，单次调用仅能接收一行输入，直接回车将返回空字符串。同时补充函数基础概念：函数是可被调用的功能模块，调用格式为`函数名(参数列表)`，来源分为内置函数、标准库函数、第三方库函数、自定义函数，可通过官方文档、`help()`函数查询用法。
2.  **变量、标识符与赋值语句**：变量是存储数据的容器，需先赋值定义后使用，常量为运行过程中不可修改的值。标识符（变量名、函数名等）需遵循命名规则，由英文字母、数字、下划线组成，不能以数字开头、不能含空格、区分大小写，不可使用Python关键字；建议命名见名知意，不与内置函数重名，慎用双下划线开头的命名。赋值语句核心格式为`变量=值`，先计算右侧表达式结果，再赋值给左侧变量，支持多变量同值赋值、多变量按序赋值，可直接通过`a,b=b,a`交换两个变量值，同时提供`+=`、`-=`等复合赋值运算符，赋值语句兼具变量定义与值修改的双重功能。
3.  **表达式与运算符**：核心包括算术运算符（+、-、*、/、//整除、%取余、**幂运算等）、关系运算符（>、<、==、>=、<=、!=）、逻辑运算符（and、or、not）、点运算符；Python支持链式比较写法（如`a<b<c`），运算符优先级从高到低核心顺序为：小括号>点运算符>幂运算>乘除类运算>加减类运算>关系运算>逻辑运算>赋值运算，同优先级按从左到右顺序执行。
4.  **代码规范核心规则**：`#`开头至行尾为单行注释，用于代码说明与调试，可通过三引号包裹的多行字符串实现多行注释效果；长代码分行时，括号内断行无需续行符，其他场景行尾需加`\`续行符；Python采用强制缩进语法，分支、循环、函数、类定义中的代码块必须缩进，缩进格式直接决定程序逻辑，是初学者的核心注意事项。
5.  **程序三大基本结构**：所有复杂程序均可通过顺序、分支、循环三种结构实现，每种结构仅有一个入口和一个出口。顺序结构按代码行先后顺序执行，是最基础的结构；分支结构根据条件判断执行不同分支，通过`if-elif-else`语句实现；循环结构根据条件重复执行代码块，通过`for/while`语句实现，分支与循环是程序实现复杂逻辑的核心。
6.  **编程辅助与开发方法**：遇到问题可向身边人请教、查阅官方/线上线下教程文档、使用Python内置`help()`函数获取帮助；通用程序开发采用IPO方法，即输入（Input）-处理（Process）-输出（Output）的计算模式，可帮助初学者拆解编程问题；计算机解决问题的标准步骤为：分析问题确定计算任务→设计算法→编写程序→调试程序→维护程序。

2.1.2 浮点数类型

● float型用来存储和处理小数
● 采用IEEE 754标准
● 取值范围大约为-1.79×10308至1.79×10308
● 能精确表示的有效数字位数最多16位
● 计算机中的小数与其实际值可能存在误差

浮点数常量的两种表示方式：
● 十进制表示：
● 0.123、-4.0、3.14
● .123、-4.   （可省略小数点前/后的0，但小数点不能省略）
● 科学计数法表示：
● 2e4		表示2×104			字母e源自exponent，即指数
● -3.29e-3	表示-3.29×10-3
● 8.5E5		表示8.5×105

注意：浮点数类型和整数类型在计算机内部的表示和处理方式不同
数学中，2.0与2没有区别
程序中，2.0与2有区别
前者为float型，后者为int型
前者可能的因为误差，实际值为1.999999999999999或2.000000000000001，
而后者无误差

4．字符串的比较
● 利用比较运算符（>, >=, <, <=, ==, !=）可比较两个字符串的大小
● 比较的规则为：
● 从左到右逐个比较对应位置的两个字符的Unicode码点（Unicode code point，一个用来表示特定字符的非负整数）大小
● 一旦得出对应位置的某个字符比另一个字符的Unicode码点大/小则表示整个字符串比另一个字符串大/小，且不再往后继续比较。
● 如果两个字符串比较到最后一个字符都相同，则两个字符串的最终比较结果为相等。
● 如果前面的所有字符相同，则字符串长度大的结果大，反之则小。

关于字符的Unicode码点值：
● 内置函数ord(c)返回字符c的Unicode编码的码点（code point）
● 内置函数chr(k)返回Unicode码点值k所对应的字符。
● 码点是Unicode编码表中与字符一一对应的某个整数。

|1<br/>2<br/>3<br/>4<br/>5<br/>6<br/>7<br/>8|print(ord("张") , ord('李') , ord('A') , ord('C'))	#输出：24352 26446 65 67<br/>print(chr(24352) , chr(26446) , chr(65) , chr(67)) 	#输出：张 李 A C<br/>print("China">"America")	#输出：True<br/>print("张三"<"李四")		#输出：True<br/>print("bee"<="beer")		#输出：True<br/>print("hero"=='hero') 		#输出：True<br/>print("3"<"128")		#输出：False，注意，整数3<整数128结果则是True<br/>print("345">"40")		#输出：False，注意，整数345>整数40结果则是True|
|---|---|

数字字符串与对应的整数或小数的比较结果不完全相同。如下例所示：
● 字符串比较："123" < "4"成立，但是，整数比较：123 > 4成立。
● 字符串比较："123.4" < "4.5"成立，但是，浮点数比较：123.4 > 4.5成立。

特别提醒：
以上现象不仅仅直接反映两个数据的比较结果上，而且可能间接影响序列数据排序的结果。

## 二、程序的分支结构（3.2）
分支结构也叫**选择结构**，核心是根据条件表达式的成立与否，选择性执行不同的程序路径，是程序实现逻辑判断的核心。

### 1. 核心语法与三种基础形式
分支结构的核心语句为`if…elif…else`，语法核心规则：
- `if`为必选分支，`elif`可设置多个，`else`最多1个，均为可选；
- 条件表达式末尾必须加英文冒号`:`，分支内的语句块必须统一缩进；
- 条件表达式值为`True`时执行对应分支，`0、空字符串、空列表/元组/字典`均视为`False`，非零、非空值均视为`True`。

三种基础形式如下：
| 分支类型 | 核心语法 | 适用场景 |
|---|---|---|
| 单if型二分支 | `if 条件表达式: 语句块` | 仅需在条件成立时执行特定操作，不成立时无额外动作 |
| if-else型二分支 | `if 条件表达式: 语句块1 else: 语句块2` | 条件成立/不成立时，分别执行两套互斥的逻辑 |
| if-elif-else型多分支 | `if 条件1: 语句块1 elif 条件2: 语句块2 ... else: 语句块n` | 存在多个互斥的判断条件，需按优先级依次判断执行 |

### 2. 简化写法：if-else三元表达式
语法格式：`表达式1 if 条件表达式 else 表达式2`
- 条件成立时，整个表达式的值为`表达式1`；不成立时为`表达式2`，可大幅简化二分支的代码行数。

### 3. 分支的串联与嵌套
- **分支串联**：多个分支结构按先后顺序独立判断，各分支无前提依赖关系，体现「多个条件仅分先后，不构成前提」的逻辑。
- **分支嵌套**：一个分支结构完整包含在另一个分支的语句块内，外层条件是内层条件执行的前提，体现「外层条件满足，才会进入内层判断」的逻辑。

### 4. match-case分支结构
Python 3.10及以上版本引入，适用于**根据单个变量的不同固定取值执行对应分支**的场景，代码更简洁直观。
- 核心语法：`match 变量名: case 值1|值2: 语句块 ... case _: 兜底语句块`
- 支持多值匹配（用`|`分隔），`case _`为兜底分支，匹配所有未提前定义的取值。

## 三、程序的循环结构（3.3）
循环结构的核心是**有规律地重复执行某段代码**，核心包含两大要素：循环条件、循环体。Python提供`while`条件循环与`for`遍历循环两种实现方式。

### 1. while条件循环
- 基础语法：`while 条件表达式: 循环体语句块`，当条件表达式为`True`时，重复执行循环体，直到条件为`False`时退出。
- 拓展语法`while-else`：`else`后的语句块，仅在循环**正常结束（未被break强制中断）**时执行。
- 适用场景：循环次数预先无法确定，只能根据运行时的条件判断是否继续循环的场景（如成绩录入，直到输入end结束）。

### 2. for遍历循环
- 基础语法：`for 循环变量 in 可迭代对象: 循环体语句块`，遍历可迭代对象的每一个元素，每循环一次将元素赋值给循环变量，执行一次循环体。
- 拓展语法`for-else`：`else`后的语句块，仅在可迭代对象遍历完毕、循环正常结束时执行，被`break`中断则不执行。
- 核心配套函数`range()`：返回等差数列形式的可迭代对象，是for循环最常用的遍历对象，支持三种传参形式：
  | 传参个数 | 语法 | 生成规则 |
  |---|---|---|
  | 1个 | `range(n)` | 生成0到n-1的整数序列，步长默认为1 |
  | 2个 | `range(i, j)` | 生成i到j-1的整数序列，步长默认为1 |
  | 3个 | `range(i, j, d)` | 生成起点i、终点j（不包含）、步长d的等差数列 |
- 适用场景：循环次数预先确定，需要按序列遍历元素的场景（如固定次数的复印计数、字符串逐字符遍历）。

### 3. 循环控制关键字：break与continue
| 关键字 | 核心作用 | 对循环else块的影响 |
|---|---|---|
| break | 立即退出**当前层**循环，不再执行循环体剩余代码，直接跳到循环结构之后的代码 | 循环被break中断，else块不执行 |
| continue | 立即结束**本次**循环，跳过循环体剩余代码，直接进入下一次循环的条件判断 | 不影响循环的正常结束，else块仍会执行 |

### 4. 循环的串联与嵌套
- **循环串联**：多个循环结构按先后顺序依次执行，前一个循环完整执行完毕，才会进入下一个循环。
- **循环嵌套**：一个循环结构完整包含在另一个循环的循环体内，外层循环每执行一次，内层循环会完整遍历执行一遍，是实现复杂图案绘制、多维数据遍历的核心。

## 四、程序的异常处理（3.4）
### 1. 异常的定义
异常（Exception）是程序运行中可预见的意外错误（如除数为0、输入数据类型不匹配、文件不存在等），若不做处理，会直接导致程序崩溃。异常处理机制可让开发者将核心精力放在业务逻辑上，而非大量的错误预判代码。

### 2. 核心语法：try-except-else-finally
完整语法结构与执行逻辑如下：
```python
try:
    可能产生异常的语句块1
except 异常类型1 as 异常对象:
    匹配到异常类型1时的处理语句块
except 异常类型2:
    匹配到异常类型2时的处理语句块
except:
    未匹配到上述类型的所有异常的兜底处理语句块
else:
    try块无任何异常时，才会执行的语句块2
finally:
    无论有无异常、无论循环是否中断，必定会执行的语句块3
```
- 支持多个`except`分支分别处理不同类型的异常，也可通过`(异常1, 异常2)`合并处理同类异常；
- 可通过`as 异常对象`获取异常的详细信息，用于日志打印或问题定位。

## 五、turtle绘图库（3.5）
turtle是Python内置的标准库，通过简单的函数调用即可实现丰富的图形绘制，语法简单、趣味性强，是入门编程逻辑的常用工具。

### 1. 核心基础
- 坐标系：绘图窗口以**像素**为单位，坐标原点`(0,0)`在窗口中心，x轴水平向右，y轴垂直向上。
- 窗口控制：核心函数`setup()`设置窗口大小与位置，配套`title()`设置窗口标题、`done()/mainloop()`开启窗口事件循环、`screensize()`设置画布大小与背景。

### 2. 核心功能函数

## 一、结构化数据类型概述（4.1）
### 1. 核心价值
结构化数据类型是具备特定结构的大容量数据容器，可实现批量数据的便捷管理、存取与操作，解决了基本数据类型仅能存储单个数据的局限。

### 2. Python内置结构化数据类型分类
| 类型 | 定界符 | 核心特性 | 可变性 |
|---|---|---|---|
| 列表(list) | 中括号`[]` | 有序序列，支持索引、切片，元素可重复 | 可变 |
| 元组(tuple) | 小括号`()` | 有序序列，支持索引、切片，元素可重复 | 不可变 |
| 集合(set/frozenset) | 大括号`{}` | 无序组合，元素不可重复，仅支持不可变类型元素 | set可变，frozenset不可变 |
| 字典(dict) | 大括号`{}` | 键值对映射结构，键唯一且为不可变类型，值无限制 | 可变 |
| 字节数组(bytearray)/字节型(bytes) | 无固定定界符 | 二进制数据存储 | bytearray可变，bytes不可变 |

### 3. 关键说明
- 结构化数据类型的元素之间均以英文逗号分隔；
- 单元素元组必须加末尾逗号，格式为`(元素,)`，否则会被识别为基础数据类型；
- 空集合必须用`set()`表示，`{}`默认代表空字典。

## 二、列表类型（4.2）
列表是包含0个或多个元素的**有序可变序列**，是Python最常用的结构化数据类型；元组可视为「元素不可修改的列表」，除修改操作外，其余用法与列表完全一致。

### 1. 列表核心操作
通过列表类方法与运算符两种途径操作，核心方法如下表：

| 操作分类 | 核心方法 | 功能说明 |
|---|---|---|
| 增 | `append(e)` | 列表末尾添加单个元素e |
| | `extend(it)` | 列表末尾追加可迭代对象it的所有元素 |
| | `insert(i, e)` | 列表下标i处插入元素e |
| 删 | `clear()` | 清空列表所有元素，不改变内存地址 |
| | `pop(i)` | 弹出下标i的元素并返回该值，缺省i则弹出末尾元素 |
| | `remove(e)` | 删除列表中首个值为e的元素 |
| 改 | 直接通过下标赋值`a[i] = 新值` | 修改指定下标位置的元素 |
| 查 | `count(e)` | 统计值为e的元素出现次数 |
| | `index(e, start, end)` | 查找元素e首次出现的下标，找不到则触发异常 |
| 排序 | `sort(key, reverse)` | 列表原位排序，reverse=True为降序，缺省为升序 |
| 反转 | `reverse()` | 列表元素原位反序 |
| 复制 | `copy()` | 返回列表的浅拷贝 |

### 2. 列表推导式
列表推导式是轻量级循环生成新列表的简洁语法，核心格式：
`[元素表达式 for 循环变量 in 可迭代对象 if 过滤条件表达式]`
- 基础用法：可快速生成序列，如`[chr(ord('A')+i) for i in range(26)]`生成26个大写英文字母列表；
- 带条件过滤：仅保留满足条件的元素，如`[y for y in range(2000,2051) if y%4==0 and y%100!=0 or y%400==0]`生成2000-2050年的闰年列表。

### 3. 列表排序操作
排序是列表最常用的批量数据处理操作，分为两种核心模式：
1.  **原位排序**：排序结果直接作用于原列表，通过列表方法`aList.sort()`实现，列表是唯一支持原位排序的Python内置数据类型；
2.  **非原位排序**：排序结果存于新列表，原列表不变，通过Python内置函数`newList = sorted(aList)`实现，支持所有可迭代对象排序。

#### 排序核心规则
- 数值型数据按数学大小比较，布尔值True等价于1，False等价于0；
- 字符串按字符Unicode码点逐位比较；
- 列表/元组按对应位置元素依次比较；
- 复数、字典不支持常规大小比较；
- 可通过`key`参数自定义排序依据，`reverse`参数控制升序/降序。

---

## 三、集合类型（4.3）
集合与数学中的集合概念完全一致，是**0个或多个元素的无序、不可重复组合**，核心用于集合运算与数据去重场景。

### 1. 核心特性
- 集合元素必须是**不可变数据类型**（数值、字符串、元组等），列表、字典、集合本身不可作为集合元素；
- 元素不可重复，天然具备去重能力；
- 分为可变集合`set`与不可变冻集`frozenset`，冻集可作为字典的键、集合的元素。

### 2. 核心集合运算
以集合A、B为例，核心运算如下：

| 运算类型 | 运算符 | 方法 | 功能说明 |
|---|---|---|---|
| 交集 | `&` | `intersection()` | 返回两个集合共同拥有的元素 |
| 并集 | `|` | `union()` | 返回两个集合所有不重复的元素 |
| 差集 | `-` | `difference()` | 返回属于A但不属于B的元素 |
| 对称差集 | `^` | `symmetric_difference()` | 返回仅属于A或仅属于B的元素 |
| 子集判断 | `<=`/`<` | `issubset()` | 判断A是否为B的子集/真子集 |
| 超集判断 | `>=`/`>` | `issuperset()` | 判断A是否为B的超集/真超集 |
| 元素归属 | `in` | - | 判断元素是否在集合中 |

### 3. 常用操作方法
- 元素操作：`add(e)`添加元素、`remove(e)`删除元素、`discard(e)`删除元素（不存在不报错）、`pop()`随机弹出元素、`clear()`清空集合；
- 集合更新：`update(it)`、`intersection_update(it)`、`difference_update(it)`等，直接在原集合上执行集合运算并更新结果。

## 四、字典类型（4.4）
字典是Python中唯一的**映射类型**，通过「键(key)-值(value)对」存储数据，实现了从键到值的高效映射，是实现键值对存储、快速查找的核心数据结构。

### 1. 核心特性
- 字典由一对大括号定界，键值对格式为`key:value`，多个键值对用逗号分隔，空字典为`{}`；
- 键必须是**不可变、可哈希类型**，且全局唯一；值可以是任意数据类型，无唯一性限制；
- Python 3.6+版本中，字典会保留键值对的创建顺序；
- 按键查找值的效率极高，反向按值找键需遍历实现，效率较低。

### 2. 字典核心操作方法
| 操作分类 | 核心方法 | 功能说明 |
|---|---|---|
| 增/改 | `d[k] = v` | 键k不存在则新增键值对，存在则修改对应值 |
| | `update(a)` | 用字典/二元组可迭代对象a更新原字典，键重复则覆盖，不存在则新增 |
| | `setdefault(k, v)` | 键k不存在则设置值为v并返回v，存在则返回原有值 |
| 删 | `pop(k, val)` | 删除键k对应的键值对，返回对应值；k不存在则返回val，无val则触发异常 |
| | `popitem()` | 删除最后创建的键值对，返回元组(k,v) |
| | `clear()` | 清空字典所有键值对 |
| 查 | `get(k, v)` | 键k存在则返回对应值，不存在则返回v（缺省为None） |
| | `keys()` | 返回可迭代的字典所有键的对象 |
| | `values()` | 返回可迭代的字典所有值的对象 |
| | `items()` | 返回可迭代的字典所有键值对（二元组）的对象 |
| 复制 | `copy()` | 返回字典的浅拷贝 |

## 五、不可变类型与类型转换（4.5）
### 1. 可变与不可变类型核心区别
| 分类 | 包含类型 | 核心特性 | 哈希特性 | 应用限制 |
|---|---|---|---|---|
| 不可变类型 | int、str、tuple、frozenset、bytes | 内容数据项不可直接修改，修改会生成新对象 | 可哈希 | 可作为字典的键、集合的元素 |
| 可变类型 | list、dict、set、bytearray | 内容数据项可直接修改，修改不改变内存地址 | 不可哈希 | 不可作为字典的键、集合的元素 |

### 2. 不可变类型的间接修改
不可变类型无法直接修改内部元素，可通过间接方式实现修改效果：
- 字符串：通过切片拼接`s = s[:2] + "8" + s[3:]`、`replace()`方法实现字符替换；
- 元组：通过拼接、切片生成新元组实现内容调整。

### 3. 结构化数据类型转换
Python支持各结构化数据类型之间的灵活转换，核心转换函数：
- `list()`：可迭代对象→列表；
- `tuple()`：可迭代对象→元组；
- `set()`：可迭代对象→集合（自动去重）；
- `dict()`：二元组可迭代对象→字典；
- 字典可通过`list(d.items())`、`list(d.keys())`、`list(d.values())`转换为列表。

## 六、二维数据的处理（4.6）
二维数据是日常开发中最常见的结构化数据（表格、矩阵、数据库记录等），Python提供两种核心处理方式。

### 1. 内置数据类型嵌套处理
通过**列表嵌套、字典嵌套**实现二维/高维数据的存储与处理：
- 列表嵌套：外层列表的每个元素是一个子列表，对应表格的一行/矩阵的一行，是存储矩阵、表格数据的基础方式；
- 字典嵌套：字典的值为列表/子字典，适合存储带业务标识的结构化数据（如城市信息、人员档案）；

### 2. numpy库处理高维数据
numpy是Python数值计算的核心第三方库，专为高维数组运算设计，核心围绕`ndarray`多维数组对象展开。

#### （1）ndarray核心特性
- 同类型数据的多维容器，所有元素必须为同一数据类型；
- 支持整体运算，无需嵌套循环即可实现数组批量计算，代码更简洁、执行效率更高；
- 核心属性：`shape`（数组形状）、`ndim`（维度/秩）、`size`（元素总数）、`dtype`（元素数据类型）、`T`（数组转置）。

#### （2）核心操作
1.  **数组创建**：通过`np.array()`从列表/元组创建，或通过`np.ones()`、`np.zeros()`、`np.eye()`、`np.arange()`、`np.linspace()`创建特殊数组；
2.  **形状操作**：`reshape()`重塑数组形状、`flatten()`折叠为一维数组、`swapaxes()`交换数组轴；
3.  **数组运算**：支持对应元素的算术运算、比较运算，提供`np.add()`、`np.dot()`（矩阵乘法）、`np.abs()`等批量运算函数；
4.  **线性代数**：提供`np.linalg.det()`（行列式）、`np.linalg.inv()`（逆矩阵）、`np.linalg.solve()`（求解线性方程组）等专业函数；
5.  **索引与切片**：一维数组与列表用法一致，高维数组支持`A[i,j,k]`格式的简洁索引，也支持布尔数组索引。

## 七、random库取随机数（4.7）
random是Python内置的标准库，基于梅森旋转算法生成**伪随机数**，适用于大多数对随机性要求不高的场景；高安全级场景推荐使用secrets库。

| `choice(seq)` | 从非空序列seq中随机返回一个元素 |

### 3. 典型应用场景
抽奖程序、随机游戏开发、随机测试数据生成、模拟动画效果、概率实验模拟等。

# Python程序设计第5章 函数的设计 完整总结
本章是Python**模块化程序设计**的核心章节，系统讲解了函数的设计理念、定义与调用规则、参数设计、核心特性，同时拓展了递归函数的原理与实现，以及Python标准库`datetime`的日期时间处理方法，是实现代码复用、降低开发维护成本的关键基础。

---

## 一、函数的核心价值与基础定义
### 1. 为什么需要函数
函数是**功能明确、边界清晰、相对独立、方便重用**的代码模块，核心价值体现在：
- 实现代码复用，避免重复造轮子，提升开发效率；
- 支持自顶向下的任务分解，实现模块化设计与分工协作；
- 降低代码耦合度，让程序逻辑更清晰，更易测试与维护。

### 2. 函数的两大来源
1.  **现成函数**：Python内置函数、标准库/第三方库提供的函数，实现「拿来主义」，无需重复开发；
2.  **自定义函数**：无现成函数可用、或需要模块化设计时自行开发，可共享给他人使用。

### 3. 函数的定义语法
Python中函数必须**先定义后调用**，核心语法如下：
```python
def 函数名(参数列表):
    函数体
    return 返回值
```
- `def`是Python保留字，标志函数定义的开始；
- 参数列表可为空，多个参数用英文逗号分隔；
- 函数体代码必须统一缩进；
- 返回值规则：有`return 值`则返回指定值；有`return`无值、或无`return`语句，均返回`None`。

## 二、函数的调用过程（5.1.2）
一次完整的函数调用分为5个核心步骤，理解该过程是掌握函数、递归函数的关键：

| 步骤 | 核心执行逻辑 |
|---|---|
| 1. 发起函数调用 | 主程序执行到函数调用表达式，赋值动作暂停，根据函数名和实参，将程序执行权转移到被调函数 |
| 2. 执行权转移与参数传递 | 按参数类型完成实参到形参的数据传递，位置参数按位置一一对应，关键字参数按名称匹配 |
| 3. 执行函数体 | 执行函数体内的代码，实现函数核心功能；若函数体中再次发起函数调用，会形成嵌套调用，当前函数执行暂停，执行权转移到新的被调函数 |
| 4. 函数返回 | 执行到`return`语句或函数体结束时，函数运行终止，返回指定值；执行权准备回到主调函数，函数内的局部变量被内存回收 |
| 5. 主调处接续执行 | 执行权回到主程序的函数调用处，函数调用表达式被替换为返回值，继续执行后续代码（如赋值、打印等），完成一次完整的函数调用 |

> 函数嵌套调用遵循「先调用后返回」的栈式执行逻辑，内层函数执行完毕并返回后，外层函数才会继续执行。

---

## 三、函数的参数设计（5.1.3）
参数是函数与外部数据交互的接口，Python提供了丰富的参数形式，适配不同的设计需求，各类参数有严格的顺序要求。

### 1. 位置参数
- 最基础的参数形式，函数调用时，实参按形参的位置顺序一一对应传递；
- 要求实参与形参的个数必须完全匹配，参数较多时可读性较差。

### 2. 可变个数参数
- 语法：形参前加单星号`*`，调用时传入的多个实参会自动打包成一个**元组**，传递给该形参；
- 适用场景：实参个数无法预先确定的场景，Python内置函数`print()`的第一个形参就是可变个数参数。

### 3. 关键字参数
通过`形参名=实参`的形式传递参数，实参顺序可任意，形参与实参的对应关系更清晰，分为两种形式：
| 形式 | 语法规则 | 核心特性 |
|---|---|---|
| 必须的关键字参数 | 形参前必须有`*`（单独`*`或可变个数参数），形参定义与位置参数一致 | 调用时必须用`形参名=实参`的形式传递，关键字名必须与形参名完全匹配 |
| 任意的关键字参数 | 形参前加双星号`**` | 调用时传入的多个`关键字名=实参`会自动打包成一个**字典**，传递给该形参 |

> 位置参数也可以通过关键字参数的形式调用，此时实参的顺序可任意调整。

### 4. 参数默认值
- 语法：`形参名=缺省值`，调用函数时若未给该形参传值，则自动使用默认值；
- 语法规则：**设置了默认值的参数，必须位于无默认值的参数之后**；
- 适用场景：参数的大部分场景使用固定值，仅少数场景需要修改，可简化函数调用。

### 5. 各类形参的顺序要求
为避免歧义，Python对不同类型形参的排列顺序有严格规定：
`位置参数 → 可变个数参数 → 必须的关键字参数 → 可变个数的关键字参数`

---

## 四、局部变量与全局变量（5.1.4）
变量的作用域由其定义位置决定，分为全局变量与局部变量，核心规则如下：

| 变量类型 | 定义位置 | 作用范围 | 核心特性 |
|---|---|---|---|
| 全局变量 | 函数之外定义的变量 | 程序执行全过程有效 | 函数内可只读访问，直接赋值会被识别为局部变量 |
| 局部变量 | 函数内部使用的变量（包括形参、函数内定义的变量） | 仅函数执行时在函数内部有效，函数返回后被释放 | 与全局变量同名时，函数内局部变量优先级更高 |

### 1. 函数内修改全局变量
若需要在函数内修改全局变量，必须通过`global`关键字显式声明该变量为全局变量，否则会被识别为新的局部变量。

### 2. 可变类型参数的特殊特性
- 若函数形参为**列表、字典**等可变数据类型，修改形参的**内容数据项**，会影响到对应的实参（二者指向同一块内存空间）；
- 若给形参整体重新赋值，则不会影响实参，仅改变形参的指向。

## 五、函数的高级特性
### 1. 函数作为参数（5.1.5）
Python中函数名可作为另一个函数的实际参数，在被调函数中可调用传入的函数，是实现灵活逻辑扩展的核心方式。
- 典型应用1：事件处理，如`turtle`库的鼠标点击事件，将绘图函数作为事件处理函数传入；
- 典型应用2：自定义排序规则，列表`sort()`方法、内置函数`sorted()`的`key`参数，传入自定义函数指定排序依据。

### 2. lambda匿名函数（5.1.6）
- 适用场景：函数的逻辑仅需一个表达式就能返回值，无需用`def`定义命名函数；
- 核心语法：`lambda 参数列表 : 返回值的表达式`；
- 高频使用场景：配合`sort()`/`sorted()`的`key`参数，实现简短的自定义排序规则，简化代码。

## 六、递归函数（5.2）
### 1. 核心定义与适用场景
- 定义：在调用一个函数的过程中，直接或间接调用该函数本身，这个函数就是递归函数；
- 适用场景：**原问题与子问题具有自相似性**的场景，如分形图形绘制、阶乘计算、斐波那契数列、目录遍历等。

### 2. 递归函数的两大核心要素
1.  **递归终止条件（基线条件）**：问题分解的终点，触发该条件时返回已知解，避免无限递归导致栈溢出；
2.  **递归递推公式**：将原问题分解为规模更小、逻辑与原问题一致的子问题，通过子问题的解推导原问题的解。

### 3. 递归函数的执行逻辑
递归函数的执行分为两个阶段：
1.  **递推阶段**：从原问题开始，逐层分解为子问题，直到触发递归终止条件，得到最底层的已知解；
2.  **回溯阶段**：从最底层的已知解开始，逐层向上反推，依次得到各层子问题的解，最终得到原问题的解。

> 典型示例：阶乘计算`n!`，终止条件为`n=0`时返回1，递推公式为`n! = n × (n-1)!`。

## 七、日期时间标准库datetime（5.3）
`datetime`是Python处理日期时间的标准库，基于`time`库封装，功能更全面，支持的年份范围为1-9999，不受`time`库1970-2038的范围限制，是Python日期时间处理的首选方案。

### 1. 核心类
| 类名 | 核心功能 |
|---|---|
| `datetime.date` | 日期类，处理年、月、日相关信息与操作 |
| `datetime.time` | 时间类，处理时、分、秒、微秒相关信息与操作 |
| `datetime.datetime` | 日期时间类，同时包含date和time的全部功能，最常用 |
| `datetime.timedelta` | 时间间隔类，用于日期时间的增量/差值计算 |
| `datetime.tzinfo` | 时区信息类，处理时区相关逻辑 |

### 2. 核心操作
#### （1）获取当前日期时间
- `datetime.today()`：获取当前本地日期时间，不支持时区设置；
- `datetime.now()`：获取当前日期时间，支持设置时区参数，缺省时为本地时间；
- `datetime.utcnow()`：获取当前UTC世界统一时间。

#### （2）构造指定日期时间对象
支持多种构造方式：
1.  直接构造：`datetime(年, 月, 日, 时, 分, 秒, 微秒)`；
2.  组合构造：`datetime.combine(date对象, time对象)`；
3.  字符串解析：`fromisoformat()`解析ISO格式字符串、`strptime()`按自定义格式解析字符串；
4.  日历构造：`fromisocalendar(年, 周, 星期)`按ISO日历构造。

#### （3）日期时间格式化
- `strftime(格式控制符)`：将datetime对象转换为指定格式的日期时间字符串；
- f-string格式化：在f前缀字符串中，直接通过`{dtObj:格式控制符}`实现格式化；
- 常用格式控制符：`%F`（年月日，YYYY-MM-DD）、`%T`（时分秒，HH:MM:SS）、`%Y`（4位年份）、`%m`（月份）、`%d`（日期）、`%H`（24小时制小时）、`%M`（分钟）、`%S`（秒）。

#### （4）日期时间运算
- 比较运算：两个datetime对象可通过`>、<、==`等运算符比较大小；
- 差值计算：两个datetime对象相减，结果为`timedelta`时间间隔对象，可通过`days`、`seconds`属性获取天数、秒数差值；
- 增量运算：datetime对象与timedelta对象相加/减，得到增减指定时间后的新datetime对象；
- 字段修改：通过`replace()`方法修改年、月、日、时、分、秒等字段，返回新的datetime对象。

## 一、文件操作基础与核心概念
### 1. 内存与外存的数据存储特性
程序处理的数据分为内存存储和外存存储两种形式，二者优势互补，是文件操作的底层逻辑基础：

| 存储介质 | 核心特性 | 优势 | 局限性 | 对应物理部件 |
|---|---|---|---|---|
| 内存 | 数据以变量/对象形式存在，掉电丢失 | 读写速度极快，适合数据实时处理 | 单位容量成本高、容量小、数据无法持久化 | 内存条、RAM |
| 外存 | 数据以文件形式存在，掉电不丢失 | 单位容量成本低、容量大、数据可持久化存储 | 读写速度慢，不适合高频实时处理 | 机械硬盘、SSD、U盘、闪存卡 |

### 2. 文本文件与二进制文件
从程序读写角度，文件分为**文本文件**和**二进制文件**两大类，二者本质均为二进制字节序列，核心差异在于数据格式与解析方式：

| 维度 | 文本文件 | 二进制文件 |
|---|---|---|
| 数据格式 | 基于特定字符编码标准的字符串序列 | 遵循公开/非公开规范的二进制字节序列 |
| 可读性 | 方便人类直接阅读、易于解析 | 未知格式无法解析，不适合人类直接阅读 |
| 典型文件 | .txt记事本文件、.py源代码文件、.csv逗号分隔文件 | 图片(png/jpg)、音视频(mp3/mp4)、Office文档、可执行程序、压缩包 |
| 读写特点 | 适合顺序读写，随机读写定位困难 | 支持随机读写，可根据格式规范精准定位到指定数据位置 |
| 打开模式 | 文本模式`t` | 二进制模式`b` |
| 读写数据类型 | 字符串`str`对象 | 字节`bytes`对象 |

## 二、文件的打开与关闭（6.1）
文件读写的标准流程为**打开文件→读写文件→关闭文件**三部曲，其中打开是前提，关闭是保障数据完整性的关键。

### 1. 文件打开：open()函数
核心语法：`fileObject = open(filename, mode, encoding)`
#### （1）核心参数详解
| 参数 | 功能说明与关键注意事项 |
|---|---|
| `filename` | 文件名字符串，支持相对路径/绝对路径；路径分隔符可用`/`，或用`\\`/`r前缀字符串`表示`\`，避免与转义字符冲突 |
| `mode` | 文件打开模式，字符串形式，默认值为`rt`（文本只读模式）；可组合基础模式与功能模式 |
| `encoding` | 文本文件的字符编码标准，常见值为`GBK`、`GB18030`、`UTF-8`；**必须以关键字参数形式调用**，读写文件需使用相同编码避免乱码 |

#### （2）mode打开模式全解
| 基础模式 | 核心含义 | 异常场景 |
|---|---|---|
| `r` | 只读模式，文件指针位于文件开头 | 文件不存在抛出`FileNotFoundError` |
| `w` | 创建覆盖模式，文件不存在则新建，存在则完全覆盖 | 无异常，原有文件内容会被清空 |
| `x` | 独占创建模式，文件不存在则新建，存在则报错 | 文件已存在抛出`FileExistsError` |
| `a` | 追加模式，文件不存在则新建，存在则在文件末尾追加内容 | 无异常，不会覆盖原有文件内容 |

| 功能模式 | 核心含义 | 组合规则 |
|---|---|---|
| `t` | 文本模式，按字符串解析文件内容 | 与`r/w/x/a`组合，默认开启 |
| `b` | 二进制模式，按字节序列解析文件内容 | 与`r/w/x/a`组合，用于二进制文件读写 |
| `+` | 增加读写功能，在原模式基础上支持同时读写 | 与`r/w/x/a`组合，如`r+`、`a+` |

### 2. 文件关闭的两种方式
#### （1）显式调用close()方法
语法：`fileObject.close()`
手动关闭打开的文件，释放系统资源；需配合异常处理机制，确保文件即使发生异常也能正常关闭。

#### （2）with上下文管理（推荐用法）
Python文件对象支持上下文管理协议，`with`语句会在离开上下文时**自动关闭文件**，无需显式调用`close()`，是Python文件操作的最佳实践，能有效避免资源泄漏。
```python
with open(filename, mode) as fObject:
    # 读写文件的核心代码
# 离开with块后，文件自动关闭
```

## 三、文本文件的读写（6.2）
文本文件的读写核心围绕文件对象的内置方法实现，支持逐行、逐字符、全量读写三种模式，适配不同的文件大小与业务场景。

### 1. 文本文件核心读写函数
| 函数名 | 核心功能说明 |
|---|---|
| `read(size)` | 读取文件剩余全部内容；指定`size`则读取前`size`长度的字符串 |
| `readline(size)` | 读取文件的下一行；指定`size`则读取该行前`size`长度的字符串 |
| `readlines(hint)` | 读取文件剩余所有行，以列表形式返回；指定`hint`则读取前`hint`行 |
| `write(str)` | 将字符串`str`写入文件，返回写入的字符数 |
| `writelines(lines)` | 将字符串列表`lines`中的所有元素依次写入文件 |
| `seek(offset, whence)` | 移动文件读写指针，`whence=0`以文件开头为基准，`1`以当前位置为基准，`2`以文件末尾为基准 |

### 2. 三种核心读写模式
#### （1）逐行读写
- 适用场景：大文件读写、按行处理数据的场景（如日志解析、表格数据处理、代码行号添加），内存占用低。
- 核心实现：可通过`for循环遍历文件对象`、`while循环+readline()`两种方式实现逐行读取；通过循环+`write()`实现逐行写入。
- 关键注意事项：可通过字符串处理过滤空行、去除/保留行尾换行符`\n`。

#### （2）逐字符读写
- 适用场景：需要对单个字符进行处理的场景（如文本加密解密、字符替换、编码转换）。
- 核心实现：通过循环读取单个字符，处理后写入新文件；本章示例为基于Unicode码值偏移的简单加密/解密算法。

#### （3）一次性全量读写
- 适用场景：小文件读写、需要一次性获取全部内容的场景，代码简洁，执行效率高。
- 核心实现：
  - 全量读取：`read()`一次性读取全部内容为单个字符串；`readlines()`一次性读取全部行为字符串列表。
  - 全量写入：`write()`写入完整字符串；`writelines()`写入字符串列表。
- 关键注意事项：大文件一次性读入会占用大量内存，需谨慎使用；读取后再次读取需通过`seek(0,0)`将指针重置到文件开头。

## 四、常见二进制文件的读写（6.3）
二进制文件需遵循特定的格式规范，Python通常通过成熟的第三方库实现读写与处理，无需手动解析底层字节序列。本章重点讲解三类最常用的二进制文件处理方案。

### 1. Excel文件读写（openpyxl库）
`openpyxl`是处理Excel 2007+版本`.xlsx`文件的主流第三方库，使用前需先通过`pip install openpyxl`安装。

#### （1）Excel核心对象
- 工作簿`Workbook`：对应一个Excel文件，一个工作簿至少包含一个工作表；
- 工作表`Worksheet`：Excel中的sheet页，包含多个单元格；
- 单元格`Cell`：Excel中的最小数据单元，**行号、列号均从1开始**，而非Python默认的0。

#### （2）核心常用操作
| 功能场景 | 代码示例 | 关键说明 |
|---|---|---|
| 创建工作簿 | `wbook = openpyxl.Workbook()` | 自动创建默认工作表 |
| 打开已有工作簿 | `wbook = load_workbook('data.xlsx')` | 目标文件必须存在 |

| 追加数据 | `sheet.append(列表/元组/字典)` | 在工作表末尾追加一行数据 |
| 保存工作簿 | `wbook.save('data.xlsx')` | 同名文件会被直接覆盖 |

### 2. 图像文件处理（PIL/Pillow库）
PIL（Python Image Library）是Python图像处理的主流库，安装命令为`pip install pillow`，**程序导入时库名为PIL，而非pillow**。

#### （1）核心模块与对象
- 核心模块：`Image`（图像基础操作）、`ImageFilter`（图像滤镜）、`ImageEnhance`（图像增强）；
- 核心对象：`Image`类，对应一张图片，封装了图像的全部属性与操作方法。

#### （2）核心操作分类
| 操作类型 | 核心功能与常用方法 |
|---|---|
| 图像创建与打开 | `Image.open()`打开图像文件；`Image.new()`创建新图像；`Image.fromarray()`从numpy数组创建图像 |
| 图像属性获取 | `format`（文件格式）、`mode`（色彩模式）、`size`（宽高二元组）、`width/height`（宽/高） |
| 图像内容访问 | `crop()`截取指定区域、`getpixel()`获取指定位置像素值、`split()`分离颜色通道、`merge()`合并通道 |
| 图像变换 | `resize()`缩放、`rotate()`旋转、`thumbnail()`生成缩略图、`transpose()`翻转/90°步长旋转 |

| 图像增强 | `ImageEnhance`模块实现亮度、对比度、颜色平衡、锐度的调整 |
| 图像保存与显示 | `save()`保存图像到文件、`show()`调用系统工具显示图像 |

#### （3）关键色彩模式
常用模式包括：`1`（1bit黑白图）、`L`（8bit灰度图）、`RGB`（真彩色）、`RGBA`（真彩色+透明通道）、`CMYK`（印刷四色模式）。

### 3. 音频文件处理（wav库）
Python内置`wav`库支持对`.wav`波形音频文件的基础读写与处理，本章核心示例为音频播放速度的调整，通过修改音频采样参数实现倍速/慢速播放效果。

### 4. Office文档高阶处理方案
| 处理方式 | 核心原理 | 优势 | 局限性 |

## 五、文件/文件夹管理（6.4）
文件/文件夹管理是将文件/文件夹作为整体进行批量操作，区别于读写文件内部内容，核心通过Python标准库`os`和`shutil`实现。

### 1. 文件夹遍历：os.walk()函数
`os.walk()`是Python遍历文件夹层级结构的核心工具，可递归遍历目标文件夹下的所有子文件夹与文件。
#### （1）核心语法
```python
import os
aTree = os.walk(top)  # top为待遍历的目标文件夹路径
for root, dirs, files in aTree:
    # 遍历处理逻辑
```
#### （2）返回值解析
每次循环返回一个三元组`(root, dirs, files)`：
- `root`：当前遍历到的文件夹的绝对路径字符串；
- `dirs`：当前文件夹下所有子文件夹名组成的列表；
- `files`：当前文件夹下所有文件名组成的列表。

> 仅需遍历目标文件夹下的一级文件（不递归子文件夹），可通过`next(os.walk(top))[2]`快速获取文件名列表。

### 2. 文件/文件夹批量操作核心函数

| | `os.makedirs(path)` | 递归创建文件夹，自动创建路径中不存在的中间文件夹 |

## 7.2 异常处理的核心语法
### 7.2.1 基础异常捕获：`try-except` 结构
这是Python异常处理的核心语法，用于捕获并处理指定代码块中触发的异常，语法格式如下：
```python
try:
    # 可能触发异常的代码（如文件打开、数据读取、数值计算）
except 目标异常类型:
    # 异常触发时，执行的容错/兜底代码
```

**贴合前序知识点的示例（文件操作）**：
```python
# 读取农业气象数据文件，处理文件不存在的场景
try:
    f = open("farm_weather_2026.csv", "r", encoding="utf-8")
    data = f.read()
    print("数据读取成功")
except FileNotFoundError:
    print("错误：气象数据文件不存在，请检查文件路径")
```

### 7.2.2 多分支异常捕获与全量捕获
针对同一段代码可能触发的多种异常，可通过多分支`except`分别处理，也可通过`Exception`捕获所有常规异常，避免程序崩溃。
```python
try:
    f = open("farm_yield.csv", "r", encoding="utf-8")
    # 读取产量数据并转换为数值
    yield_data = float(f.readline())
except FileNotFoundError:
    print("错误：产量数据文件不存在")
except ValueError:
    print("错误：产量数据格式异常，无法转换为数值")
except Exception as e:
    # 捕获其他所有异常，e为异常详情
    print(f"程序运行出错，错误详情：{e}")
```

### 7.2.3 `else` 与 `finally` 扩展子句
1.  **`else` 子句**：仅当`try`代码块**无任何异常触发**时执行，用于存放正常执行后的业务逻辑。
2.  **`finally` 子句**：无论`try`代码块是否触发异常，**最终一定会执行**，常用于资源释放（如第6章的文件关闭操作），是保障资源安全的核心语法。

**完整语法示例（贴合文件操作场景）**：
```python
f = None
try:
    f = open("farm_sensor_data.csv", "r", encoding="utf-8")
    content = f.read()
except FileNotFoundError:
    print("传感器数据文件不存在")
except Exception as e:
    print(f"数据读取失败：{e}")
else:
    print("文件读取完成，无任何异常")
finally:
    # 无论是否出错，都关闭文件，避免资源泄露
    if f is not None:
        f.close()
        print("文件已安全关闭")
```

### 需求：农田传感器数据批量处理容错程序
结合第6章的文件/文件夹管理、本章的异常处理，实现批量处理农田传感器数据文件的健壮程序，需求如下：
1.  遍历指定文件夹内的所有气象数据csv文件
2.  遇到文件无法打开、权限不足的异常，记录错误并跳过该文件，不中断整体程序
3.  读取文件时，遇到数据格式错误的行，记录异常并跳过该行
4.  对温度、湿度数据做阈值校验，超出合理范围触发自定义异常并标记
5.  无论程序是否出错，最终都关闭所有文件、保存处理结果与异常日志

```python
import os

# 自定义异常
class SensorDataError(Exception):
    pass

# 数据校验函数
def check_sensor_data(temp, humidity):
    if temp < -40 or temp > 60:
        raise SensorDataError(f"温度{temp}℃超出合理范围")
    if humidity < 0 or humidity > 100:
        raise SensorDataError(f"湿度{humidity}%超出合理范围")
    return True

# 主程序
if __name__ == "__main__":
    data_dir = "./farm_sensor_data"  # 传感器数据文件夹（第6章路径管理）
    log_file = "./process_error.log"
    success_count = 0
    error_file_count = 0
    error_line_count = 0

    # 遍历文件夹（第6章文件夹管理）
    for file_name in os.listdir(data_dir):
        if not file_name.endswith(".csv"):
            continue
        file_path = os.path.join(data_dir, file_name)
        f = None

        try:
            f = open(file_path, "r", encoding="utf-8")
            lines = f.readlines()
            print(f"开始处理文件：{file_name}")

            # 逐行处理数据
            for line_num, line in enumerate(lines[1:], start=2):  # 跳过表头
                try:
                    # 拆分数据并转换类型
                    date, temp_str, humidity_str = line.strip().split(",")
                    temp = float(temp_str)
                    humidity = float(humidity_str)
                    # 数据校验
                    check_sensor_data(temp, humidity)
                except ValueError:
                    error_line_count += 1
                    error_msg = f"文件{file_name}第{line_num}行：数据格式错误"
                    print(error_msg)
                    # 写入错误日志
                    with open(log_file, "a", encoding="utf-8") as log_f:
                        log_f.write(error_msg + "\n")
                except SensorDataError as e:
                    error_line_count += 1
                    error_msg = f"文件{file_name}第{line_num}行：{e}"
                    print(error_msg)
                    with open(log_file, "a", encoding="utf-8") as log_f:
                        log_f.write(error_msg + "\n")

            success_count += 1
            print(f"文件{file_name}处理完成")

        except FileNotFoundError:
            error_file_count += 1
            print(f"错误：文件{file_name}不存在")
        except PermissionError:
            error_file_count += 1
            print(f"错误：无权限读取文件{file_name}")
        except Exception as e:
            error_file_count += 1
            print(f"文件{file_name}处理失败：{e}")
        finally:
            # 确保文件关闭
            if f is not None:
                f.close()

    # 输出处理统计结果
    print("="*50)
    print(f"处理完成！成功处理文件数：{success_count}")
    print(f"异常文件数：{error_file_count}，异常数据行数：{error_line_count}")
    print(f"错误日志已保存至：{log_file}")
```

本案例通过网络爬虫技术自动化采集全国农产品市场官方数据，结合数据可视化技术实现农业生产数据的图形化呈现，为农业生产决策提供数据支撑。

#### 1. 核心技术与用到的Python库
- **网络数据采集**：`requests`库实现HTTP请求，`BeautifulSoup4`库实现HTML网页解析；
- **数据处理**：Python内置JSON解析、列表与字典操作；
- **数据可视化**：`matplotlib`库绘制各类统计图表，`numpy`库辅助数值计算。

#### 2. 网络爬虫核心原理与流程
网络爬虫通过模仿用户浏览器行为，自动化访问网页、提取目标数据，核心执行流程为：**发送请求→接收响应→解析内容→异常处理→数据存储**，同时需遵循网站`robots.txt`规则，设置合理请求间隔，避免对服务器造成压力。
- **GET请求**：用于获取URL中携带参数的公开数据，如各省生猪存栏量、出栏量数据；
- **POST请求**：用于需要在请求体中携带JSON参数的场景，如生猪生产走势、饲料产量历史数据。

#### 3. 核心实现流程
1.  **目标网站分析**：通过浏览器开发者工具，分析全国重点农产品市场信息平台的请求URL、请求方式、请求头与请求参数；
2.  **数据请求获取**：用`requests`库发送GET/POST请求，关闭SSL验证避免报错，获取JSON格式的农业生产数据；
3.  **数据解析清洗**：解析JSON响应内容，提取省份名称、生猪存栏量/出栏量、统计时间、饲料产量等核心字段，处理缺省值与异常数据；
4.  **可视化图表绘制**：配置matplotlib中文字体，避免中文乱码，基于清洗后的数据绘制三类核心图表：
    - 横向柱状图：2022年各省生猪存栏量/出栏量对比；
    - 折线图：全国能繁母猪存栏占比、同比/环比月度走势；
    - 多组柱状图：2022-2024年全国生猪生产季度走势、2014-2022年生猪饲料产量年度趋势。

#### 4. 核心成果
实现了全国生猪产业核心数据的自动化采集与更新，通过可视化图表直观呈现了生猪生产的区域分布、时间维度变化趋势，为生猪产业的生产规划、市场决策提供了直观的数据支撑，可迁移到粮食产量、农产品价格、农资供需等其他农业数据场景。

### 案例3：鸢尾花分类
本案例通过机器学习技术，基于鸢尾花的形态特征实现物种智能分类，是智慧农业中农作物品种识别、病虫害智能分类、产量预测等场景的基础原型。

#### 1. 核心技术与用到的Python库
- **数据加载与处理**：`pandas`库实现Excel数据集的读取、特征与标签分离；
- **机器学习建模**：`scikit-learn`库实现数据集划分、数据预处理、模型构建、训练与评估。

#### 2. 数据集说明
鸢尾花数据集是机器学习经典数据集，包含150个样本，分为3个物种类别，每类50个样本；每个样本包含4个核心特征：花萼长度、花萼宽度、花瓣长度、花瓣宽度（单位：厘米）。

#### 3. 核心实现流程（机器学习标准建模流程）
1.  **数据加载**：通过`pandas.read_excel()`读取Excel数据集，分离标签（物种类别）与特征（4项形态指标）；
2.  **数据集划分**：用`train_test_split()`将数据集随机划分为**训练集（80%）**与**测试集（20%）**，设置随机种子保证结果可复现；
3.  **数据预处理**：用`StandardScaler()`对特征数据进行标准化处理，消除量纲影响，提升模型训练效果；
4.  **模型构建**：选择支持向量机分类模型`SVC`，设置正则参数C=1.0，选用线性核函数；
5.  **模型训练**：用预处理后的训练集数据拟合模型，完成模型参数学习；
6.  **模型预测与评估**：用训练好的模型对测试集数据进行预测，通过`accuracy_score()`计算预测准确率，评估模型性能。

#### 4. 核心成果
本案例构建的SVM分类模型，在鸢尾花测试集上的预测准确率达到**96.67%**，实现了基于形态特征的物种高精度智能分类。该建模流程可直接迁移到智慧农业的核心场景，包括农作物品种识别、病虫害严重程度分类、作物产量等级预测、农产品品质分级等。
