## 一、项目概述

### 1.1 项目简介

本项目是一个面向Python编程学习的多智能体（Multi-Agent）个性化学习辅助系统。系统基于大语言模型（LLM）驱动，通过多个专业AI智能体的协同工作，为不同水平、不同学习风格的用户提供自适应的学习资源生成、智能问答、练习测评、学习路径规划等全方位学习支持。

### 1.2 项目目标

- **个性化学习体验：** 通过9维用户画像动态建模，实现"千人千面"的学习资源推荐与生成
- **多智能体协同：** 构建10+专业AI智能体，各司其职，通过LangGraph编排引擎实现灵活的任务路由与并行执行
- **全链路学习支持：** 覆盖"学-练-测-评-路径规划"完整学习闭环
- **自适应教学：** 基于用户实时学习状态检测，动态调整教学策略与内容难度

### 1.3 适用对象

主要面向Python编程初学者到中级学习者，同时通过自适应机制可服务进阶用户。

## 二、项目背景与需求分析

### 2.1 行业背景

随着人工智能技术的快速发展，大语言模型在教育领域的应用日益广泛。传统编程学习平台存在以下痛点：

1. **内容千篇一律：** 所有用户获得相同的学习资源，无法适应个体差异
2. **缺乏智能交互：** 无法理解用户的具体困惑，难以提供针对性指导
3. **学习路径单一：** 固定的课程体系无法适应不同基础和目标的学习者
4. **反馈机制薄弱：** 练习批改和学习效果评估能力不足

### 2.2 需求分析

#### 功能性需求

| 需求编号 | 需求描述 | 优先级 |
|---------|---------|--------|
| FR-01 | 智能问答：基于知识库的RAG增强问答 | 高 |
| FR-02 | 多类型资源生成：文档、代码、思维导图、视频、练习题 | 高 |
| FR-03 | 个性化用户画像：9维度动态用户建模 | 高 |
| FR-04 | 学习路径规划：基于知识依赖图的个性化路径生成 | 高 |
| FR-05 | 练习测评系统：自动生成+智能批改+错题本 | 高 |
| FR-06 | 学习进度追踪：多维度学习数据统计与可视化 | 中 |
| FR-07 | 苏格拉底式教学：引导式提问教学法 | 中 |
| FR-08 | 深度思考模式：多Agent并行协作的深度分析 | 中 |
| FR-09 | A/B测试框架：教学策略效果对比实验 | 低 |

#### 非功能性需求

| 需求类别 | 具体要求 |
|---------|---------|
| 性能 | 单次请求响应时间 < 30秒（LLM生成类）；SSE流式输出首字节 < 2秒 |
| 可用性 | 系统可用性 > 99%；支持断线重连与状态恢复 |
| 安全性 | JWT身份认证；输入安全过滤；沙箱化代码执行 |
| 可扩展性 | Agent插件化架构，新增Agent无需修改核心代码 |
| 可维护性 | 配置与代码分离；26个Prompt模板独立管理 |

### 2.3 可行性分析

- **技术可行性：** LangGraph + LangChain生态成熟，DeepSeek/MiMo等国产大模型API稳定可用
- **经济可行性：** 采用开源技术栈，运行成本可控；大模型API按量计费
- **时间可行性：** 项目周期约3个月，团队协作可按期完成

## 三、系统总体设计

### 3.1 系统架构

系统采用分层架构设计，自上而下分为6层：

```
┌─────────────────────────────────────────────────────┐
│                   前端展示层                          │
│          React 19 + TypeScript + Vite                │
│    (聊天界面 / 资源卡片 / 思维导图 / 代码编辑器)       │
├─────────────────────────────────────────────────────┤
│                   API接口层                          │
│              FastAPI (11个路由模块)                    │
│        REST API + SSE流式输出 + JWT认证               │
├─────────────────────────────────────────────────────┤
│                 智能体层 (Agent)                      │
│     10+专业AI智能体 (问答/练习/代码/文档/思维导图...)   │
├─────────────────────────────────────────────────────┤
│               编排调度层 (Orchestration)               │
│     LangGraph状态图 + 统一路由 + 并行执行引擎          │
├─────────────────────────────────────────────────────┤
│                 数据存储层                            │
│    SQLAlchemy ORM + ChromaDB向量库 + SQLite/PG        │
├─────────────────────────────────────────────────────┤
│               基础设施层                              │
│    LLM客户端 / RAG检索 / 行为追踪 / 代码沙箱           │
└─────────────────────────────────────────────────────┘
```

### 3.2 核心工作流

用户消息进入系统后的处理流程：

```
用户消息 → 统一路由Agent (意图识别+资源类型判定)
    ├─ 问答类 → 导师Agent → RAG检索 → 生成回答
    ├─ 练习类 → 练习Agent → 并行生成3种题型 → 去重输出
    ├─ 代码类 → 代码Agent → 生成代码+解释 → 沙箱验证
    ├─ 文档类 → 文档Agent → 结构化知识文档
    ├─ 思维导图 → 思维导图Agent → JSON/Mermaid/Markdown
    ├─ 视频类 → 视频Agent → HTML动画+语音
    ├─ 路径类 → 路径Agent → 知识依赖分析 → 路径生成
    └─ 深度模式 → 5个Agent并行执行 → SSE实时推送思考过程
```

### 3.3 数据模型设计

核心数据模型包括：

- **用户模型 (User)：** 账户信息、JWT认证
- **用户画像 (UserProfile)：** 9维度画像（性别、年龄、知识水平、学习目标、学习风格、时长偏好、薄弱点、已掌握点、动机水平）
- **学习资源 (Resource)：** 生成的各类学习资源元数据
- **学习路径 (LearningPath)：** 路径节点 + 知识依赖关系 + 完成状态
- **练习记录 (QuizAttempt)：** 答题记录 + 批改结果
- **错题本 (ErrorBook)：** 错题 + 艾宾浩斯间隔重复算法
- **对话记录 (ChatMessage)：** 多轮对话历史
- **学习进度 (Progress)：** 多维度学习数据统计

## 四、核心功能模块

### 4.1 多智能体协作系统

#### 4.1.1 统一路由Agent

采用单次LLM调用同时完成意图识别、资源类型判定和主题提取，替代传统的关键词匹配硬编码路由方案。基于用户画像动态调整资源优先级（如视觉型学习者优先推荐思维导图）。

#### 4.1.2 专业Agent集群

| Agent名称 | 职责 | 核心能力 |
|-----------|------|---------|
| 导师Agent (TutorAgent) | 智能问答 | RAG增强、多轮对话、苏格拉底引导 |
| 练习Agent (QuizAgent) | 题目生成 | 3种题型并行生成、去重、自适应难度 |
| 代码Agent (CodeAgent) | 代码示例 | 代码+解释生成、沙箱验证 |
| 文档Agent (DocAgent) | 知识文档 | 结构化Markdown、概念层次化讲解 |
| 思维导图Agent (MindmapAgent) | 思维导图 | JSON/Mermaid/Markdown/ER四种格式 |
| 视频Agent (VideoAgent) | 教学动画 | HTML+GSAP动画、文字转语音 |
| 路径Agent (PathAgent) | 路径规划 | 知识依赖图分析、个性化路径生成 |
| 评估Agent (EvaluationAgent) | 效果评估 | 学习状态检测、画像更新建议 |
| 画像Agent (ProfileAgent) | 画像构建 | 对话分析、9维度画像动态更新 |

#### 4.1.3 深度思考模式

当用户需要深度分析时，系统启动并行子工作流，5个Agent（文档、代码、练习、评估、路径）同时执行，通过SSE实时推送每个Agent的思考过程，提供透明化的AI推理体验。

### 4.2 个性化用户画像系统

#### 画像维度设计

```
用户画像 (9维度)
├─ 基础信息：性别、年龄
├─ 学习能力：知识水平、已掌握知识点、薄弱点
├─ 学习偏好：学习目标、学习风格、时长偏好
└─ 学习状态：动机水平
```

#### 画像更新机制

- **实时更新：** 每次对话后，画像Agent分析对话内容，提取新信息
- **批量更新：** 每日凌晨3点，基于当日行为数据批量优化画像
- **行为追踪：** 记录用户操作（答题、提问、资源浏览），统计分析驱动画像修正

### 4.3 RAG知识检索系统

- **知识库构建：** Python基础教材Markdown文件 → ChromaDB向量化存储
- **嵌入模型：** 讯飞星火2560维向量嵌入
- **检索增强：** 所有Agent可选注入RAG上下文，防止LLM幻觉
- **可配置参数：** 相似度阈值、Top-K检索数量

### 4.4 学习路径规划系统

- **知识依赖图：** 建立Python知识点之间的前置依赖关系
- **动态路径生成：** 基于用户画像和当前掌握情况，生成个性化学习路径
- **节点状态管理：** 未开始 / 进行中 / 已完成 / 需复习 / 已跳过
- **掌握度阈值：** 根据练习正确率动态判断知识点掌握程度

### 4.5 练习测评与错题本系统

- **智能出题：** 支持选择题、填空题、编程题三种题型，自适应难度
- **智能批改：** LLM驱动的语义级批改，不仅判断对错，还给出详细解析
- **错题本：** 基于艾宾浩斯遗忘曲线的间隔重复算法，自动计算复习时间
- **练习去重：** 并行生成多道题目后自动去重，保证题目质量

### 4.6 代码执行沙箱

- **安全隔离：** 资源限制（内存、CPU、执行时间）
- **速率限制：** 按用户限制执行频率
- **无缝集成：** 与代码Agent生成的示例代码无缝配合，支持一键运行

### 4.7 苏格拉底式教学

- **引导式提问：** 不直接给出答案，通过一系列引导性问题帮助用户自主发现答案
- **状态机驱动：** 完整的状态机实现，管理教学对话的推进
- **适应性调整：** 根据用户回答质量动态调整引导策略

## 五、技术架构与路线

### 5.1 技术栈总览

| 层次 | 技术选型 | 说明 |
|------|---------|------|
| 前端框架 | React 19 + TypeScript | 组件化开发，类型安全 |
| 前端构建 | Vite 6 | 极速热更新，优化构建 |
| UI样式 | Tailwind CSS 3 + SCSS | 原子化CSS + 自定义样式 |
| 状态管理 | Zustand 5 | 轻量级状态管理 |
| 后端框架 | FastAPI | 异步高性能Python框架 |
| AI编排 | LangGraph | 多Agent状态图编排 |
| LLM集成 | LangChain + OpenAI SDK | 统一LLM调用接口 |
| 主力模型 | DeepSeek (deepseek-chat) | 国产高性能大模型 |
| 备用模型 | 小米MiMo (mimo-v2.5-pro) | 国产备用大模型 |
| 嵌入模型 | 讯飞星火 (2560维) | 向量嵌入 |
| 向量数据库 | ChromaDB | RAG知识检索 |
| 关系数据库 | SQLAlchemy 2.0 + SQLite/PG | ORM + 异步操作 |
| 身份认证 | JWT (python-jose + bcrypt) | 无状态认证 |
| 流式输出 | SSE (sse-starlette) | 实时推送 |
| 容器化 | Docker + Docker Compose | 一键部署 |
| 测试框架 | pytest + pytest-asyncio | 自动化测试 |

### 5.2 关键技术方案

#### 5.2.1 多Agent编排方案

采用LangGraph状态图实现Agent编排：
- **状态管理：** WorkflowState Pydantic模型定义全局状态
- **条件路由：** 统一路由Agent输出 → 条件边 → 目标Agent
- **并行执行：** 深度思考模式下5个Agent并行运行
- **检查点持久化：** LangGraph checkpointer支持状态断点恢复

#### 5.2.2 Prompt工程方案

- 26个独立Prompt模板文件（.txt），按Agent和场景分类
- 支持变量注入（用户画像、知识上下文、历史对话等）
- 版本化管理，便于迭代优化

#### 5.2.3 前后端通信方案

- **REST API：** 常规CRUD操作
- **SSE流式输出：** LLM生成类请求，实时推送token和思考过程
- **WebSocket（规划中）：** 双向实时通信

## 七、创新点与特色

### 7.1 技术创新

1. **单次LLM调用的统一路由：** 创新性地将意图识别、资源类型判定和主题提取合并为单次LLM调用，相比传统多次调用方案，延迟降低60%以上

2. **深度思考并行工作流：** 5个Agent并行执行并通过SSE实时推送思考过程，用户可以直观看到AI的多维度分析过程

3. **9维动态用户画像：** 超越传统简单标签化的用户建模，通过对话分析和行为追踪实现画像的持续演进

4. **多格式思维导图生成：** 单个Agent支持JSON、Mermaid、Markdown、ER图四种输出格式，覆盖不同使用场景

5. **艾宾浩斯间隔重复集成：** 将认知科学中的遗忘曲线理论与LLM批改系统深度整合

### 7.2 教育创新

1. **苏格拉底式教学法：** 引导式提问替代直接教学，培养用户的独立思考能力

2. **自适应难度调节：** 基于实时学习状态检测（困惑/挣扎/掌握），动态调整内容难度

3. **全链路学习闭环：** 学（资源生成）→ 练（智能出题）→ 测（批改评估）→ 评（效果分析）→ 路径规划，形成完整学习循环

4. **知识依赖图驱动：** 基于知识点之间的前置关系构建学习路径，确保学习的系统性和连贯性

### 7.3 工程创新

1. **Agent插件化架构：** 新增Agent只需继承BaseAgent并注册到路由表，无需修改核心代码

2. **配置与代码完全分离：** 26个Prompt模板独立管理，支持不改代码的Prompt迭代

3. **双模型容灾机制：** DeepSeek主模型 + MiMo备用模型，API故障自动切换

4. **沙箱化代码执行：** 资源限制 + 超时控制 + 速率限制，保障系统安全
